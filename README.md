# Monitor ECG TinyML

## 🛠️ Stack Tecnológico

- **Lenguaje IA:** Python 3.11
- **Procesamiento de datos:** NumPy, Pandas, SciPy
- **Dataset:** MIT-BIH Arrhythmia Database (PhysioNet)
- **Machine Learning:** TensorFlow, Keras
- **Desarrollo TinyML:** Edge Impulse
- **Inferencia local:** TensorFlow Lite Micro
- **Lenguaje de integración:** C++
- **Comunicación inalámbrica:** Bluetooth Low Energy (BLE)
- **Protocolo de comunicación:** JSON
- **Aplicación móvil:** Flutter
- **Lenguaje móvil:** Dart
- **Bluetooth móvil:** FlutterBluePlus
- **Alertas de voz:** Flutter TTS
- **Entorno de desarrollo:** Visual Studio Code
- **Control de versiones:** Git, GitHub
