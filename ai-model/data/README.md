# data/

- `raw/mitdb/`: MIT-BIH Arrhythmia Database (48 registros, unos 90 MB). Se descarga con `python -m src.training.dataset_loader --download`. **No se sube a git.**
- `processed/`: reservado para cachés de latidos. Tampoco se sube a git.

**Licencia y cita:** MIT-BIH se distribuye en PhysioNet bajo la Open Data Commons Attribution License v1.0. Hay que citar a Moody y Mark (2001), *IEEE Eng. in Medicine and Biology* 20(3):45-50, y a Goldberger et al. (2000), *PhysioNet*, Circulation 101(23):e215-e220.
