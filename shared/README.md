# shared/

Contratos y constantes que comparten el modelo, el firmware y la app.

- [`protocol/communication_contract.md`](protocol/communication_contract.md): **contrato para la app móvil**. Qué debe recibir, enviar y respetar.
- [`constants/ecg_constants.md`](constants/ecg_constants.md): tabla de constantes, con su estado (definida, provisional o pendiente del hardware) y su origen único.

La especificación normativa del protocolo está en [`communication/ble/ble_spec.md`](../communication/ble/ble_spec.md).
